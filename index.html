Windows and menus

Windows and menus, without the mouse.

Send the window in front to a half, a quarter, a third or the whole screen, nudge it a step at a time, and put it back. Yours

Make it yours.

Your settings live in one plain-text file you can read, edit and keep in git. Add your own commands, quicklinks and snippets; drop a script in a folder and it becomes a command, community script commands included. Run a shell line with :!, or turn text into JSON, a UUID or a hash.

:!git statusjsonuuid

~/.config/copperlight/config.toml
[hotkeys]
launcher = "option+space"   # ⌥Space

[[command]]
alias = "gh"
type  = "url"
url   = "https://github.com/search?q={query}"

[[command]]
alias = "dev"
type  = "shell"
run   = "cd ~/code/api && docker compose up -d"

[[snippet]]
name = "reply"
text = "Hi {query}, thanks for the note."

Questions, answered.

Is Copperlight free?

Yes. Copperlight is free and open source under the GPL-3.0. There’s no account to make and nothing to pay for.

Can Copperlight replace Spotlight?

Yes. It opens apps, finds files and does math and conversions like Spotlight, and adds window commands, menu search, snippets, timers and your own commands. Keep both, or give Copperlight Spotlight’s shortcut: the steps are below.

Which Macs does it run on?

macOS 15 Sequoia or later, on Apple silicon and Intel Macs. The download is 9 MB.

Does Copperlight send my data anywhere?

No. There’s no account, no telemetry and no AI service. It goes online only for currency rates, app descriptions (which you can turn off) and a stock price when you ask for one.

Can I add my own commands?

Yes. Quicklinks, snippets and commands go in one plain-text file, config.toml, and any script you put in its scripts folder becomes a command. Community script commands run as they are.

Is it safe to open?

Every line of Copperlight is on GitHub, where you can read it or build it yourself. The first time you open it, macOS asks you to confirm it once: the download section shows how.

How Copperlight compares with Spotlight and other launchers

Up and running in a minute.

The first time you open Copperlight, macOS asks you to confirm it. One extra click, only once.

  2. 02Open itmacOS stops it the first time. Click Done.
  3. 03Open AnywayIn System Settings → Privacy & Security, scroll down and click Open Anyway. “Copperlight” was blocked to protect your Mac.Open Anyway

Want it on ⌘Space?

Copperlight opens with ⌥Space, next to Spotlight. To give it Spotlight's key, turn off Spotlight's shortcut in System Settings → Keyboard → Keyboard Shortcuts… → Spotlight → Show Spotlight search. Then open Copperlight's Settings, click the shortcut and press ⌘Space.
